# 12-Week Cybersecurity Re-Entry Program

## Goal

Rebuild hands-on cybersecurity fluency through a balanced offensive, defensive, and purple-team program.

## Weekly Cadence

- **3-5 focused study sessions per week**
- **At least 2 hands-on labs per week**
- Record notes after every lab
- Do not advance a week until its exit criteria are met

## Week 1 — Baseline and Core Fluency

### Focus
- Linux command-line fluency
- TCP/IP, DNS, HTTP/S
- PowerShell
- Python basics
- Nmap and Wireshark
- Burp Suite orientation

### Resources
- pwn.college
- OverTheWire Bandit
- Wireshark documentation
- Nmap reference guide

### Exit Criteria
- [ ] Complete a Linux skills diagnostic
- [ ] Capture and explain a basic HTTP transaction in Wireshark
- [ ] Perform authorized host/service enumeration in a lab
- [ ] Write one useful PowerShell command or script
- [ ] Write one useful Python utility or script
- [ ] Record all work in field notes

## Week 11 — Purple-Team Validation

### Method

For each technique, answer:

1. What was executed?
2. What changed?
3. What telemetry was created?
4. Which ATT&CK technique applies?
5. Was it detected?
6. How could detection improve?
7. How could prevention improve?

### Exit Criteria
- [ ] Complete three purple-team validation cards
- [ ] Produce at least one improved detection

---

- [ ] Produce a professional finding
- [ ] Produce an incident/detection analysis
- [ ] Review skill changes from Week 1
- [ ] Select the next specialization cycle
