# Veles Cyber Lab

A public cybersecurity learning and research portfolio focused on understanding how systems fail, what evidence attacks leave behind, and how to defend them.

## Focus Areas

- Offensive security
- Web application security
- Windows and Active Directory
- Digital forensics and incident response
- Threat hunting
- Detection engineering
- Purple-team validation
- Security tooling and automation

## Current Training Cycle

This repository supports a structured 12-week cybersecurity re-entry program.

### Phase 1 — Rebuild Core Fluency
- Linux, networking, HTTP, PowerShell, Python
- Nmap, Wireshark, Burp Suite
- pwn.college and OverTheWire

### Phase 2 — Offensive Security
- PortSwigger Web Security Academy
- Authentication and access control
- SQL injection, XSS, SSRF
- API, OAuth, and JWT security

### Phase 3 — Defensive Security
- DFIR and log analysis
- Endpoint and network telemetry
- MITRE ATT&CK mapping
- Threat hunting and detection engineering

### Phase 4 — Enterprise and Purple Team
- Windows and Active Directory security
- Identity and credential attack paths
- Detection validation
- Defensive recommendations and reporting

## Responsible Use

All offensive-security work documented here is limited to systems I own, intentionally vulnerable training environments, CTFs, or systems for which I have explicit authorization to test.

This repository is intended for education, defensive improvement, and responsible security research.

## Publishing Rules

- No credentials, secrets, tokens, API keys, or client data.
- No restricted challenge flags or prohibited walkthroughs.
- No sensitive production information.
- Findings are sanitized before publication.
- Training-platform rules take precedence over portfolio goals.
